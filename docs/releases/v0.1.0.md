# BuildLens v0.1.0

The first official GitHub release of BuildLens. No PyPI publication.

BuildLens is an independent offline CLI for diagnosing recognizable CI/build
failure symptoms from local logs. It produces concise terminal, JSON, and
Markdown reports backed by actual source lines. Its runtime uses only Python's
standard library: no service, API key, telemetry, or LLM is involved.

## Included

- Gradle/Maven dependency resolution; npm dependency/lockfile failures; Python
  missing modules; permissions, storage, authentication, and GitHub Actions errors.
- Cautious explanations and investigation steps, duplicate grouping, and UNKNOWN
  results when the cause cannot be identified by the available signatures.
- Input and report limits, UTF-8/BOM UTF-16, imperfect encoding warnings, terminal
  control removal, and best-effort common secret masking.
- JSON schema version 1.0 and both `buildlens` and `python -m buildlens` entry points.
- Explicit `Documentation example:` lines remain UNKNOWN evidence; operational
  errors containing quotation marks still match. This convention does not
  identify arbitrary prose, code blocks, or timestamp-prefixed examples.

## Install

Download the wheel and `SHA256SUMS.txt` from this release. Verify the full
SHA-256 digest using PowerShell `Get-FileHash -Algorithm SHA256 <file>` or Linux
`sha256sum <file>`. Then create a Python 3.11+ virtual environment and use its
Python executable:

```sh
python -m pip install --no-index --no-deps buildlens-0.1.0-py3-none-any.whl
buildlens analyze synthetic-build.log
buildlens analyze synthetic-build.log --format json
```

This installs the already downloaded wheel without fetching runtime dependencies.
The checksums detect changed bytes; they are not independently signed provenance.
The source archive
contains synthetic samples, tests, schema documentation, and release-check tools.

## Compatibility and cautions

The pre-release hosted Ubuntu 24.04.5/Windows Server 2025 × Python 3.11–3.14
matrix passed: Ubuntu 110 tests per version; Windows 106 with four POSIX-only
skips per version. Final publication requires all eight jobs to pass on the
exact release commit, including tests, lint, formatting, wheel/sdist builds,
distribution checks and installed-wheel checks. The release page records that
commit, final run URL and artifact digests after verification.
macOS, Ubuntu 26, and other unlisted runtimes remain **UNVERIFIED**.

Rules describe symptoms, not proven causes. Quoted documentation errors can
match; localized or multiline-only errors can be missed. UNKNOWN also applies to
clean or ambiguous logs. Redaction cannot guarantee removal of confidential
information; review every report before sharing and protect original logs.

**Exit codes:** 0 means a supported symptom was found, 1 means UNKNOWN, and 2
means an input/usage or report-write error. Exit 0 never means the build passed.
